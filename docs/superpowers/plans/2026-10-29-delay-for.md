# Coro::delay_for Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 增加 header-only、Qt 无关的 `Coro::delay_for(duration)`：正常到期返回 `Result<void>` 成功，`FiberTask::cancel()` 时返回 `interrupted`。

**Architecture:** 内部创建一个无生产者的局部 `Awaitable<void>`，用 `await_for(duration)` 挂起；把 `timed_out` 映射为成功，其余错误（尤其是 `interrupted`）原样返回。不创建定时线程、不依赖 Qt、不加新类型。

**Tech Stack:** C++17、boost.fiber、Qt 5.12+/QtTest、qmake、ASan。

## Global Constraints

- 公开 API：`template<class Rep, class Period> Result<void> Coro::delay_for(const std::chrono::duration<Rep, Period>&);`
- header-only、Qt 无关；不新增公开类、定时线程或 Qt 依赖。
- 正常到期 → `Result<void>` 成功（不暴露 `timed_out`）；`FiberTask::cancel()` → `std::errc::interrupted`。
- `duration <= 0` 立即成功，不挂起。
- 只响应 `task.cancel()`；`Coro::quit()`/线程结束不提前唤醒，仍会等满 duration。
- `FiberChannel`、`ChannelHub`、`Awaitable::await_for` 零修改。
- gcc >= 9，C++17；boost >= 1.89 为目标；本地验证用 boost 1.83（`/home/ac130/boost183`）。
- 测试使用 `test/testfibertask` 的本地 wrapper；不提交 `build-*/`、`.superpowers/` 或临时文件。
- 每个 Task 一个独立 commit。

```cpp
/**
 * @brief 正常到期：delay_for 返回成功，且确实等待了约 50ms。
 */
void test_fiber_task::test_case_delay_for_normal_timeout()
{
    std::atomic_bool done{false};
    std::atomic_int  state{0}; // 1 成功，2 interrupted，3 其它
    std::atomic_llong elapsedMs{-1};

    auto task = Coro::makeTask([&]{
        const auto start = std::chrono::steady_clock::now();
        auto r = Coro::delay_for(std::chrono::milliseconds(50));
        elapsedMs.store(std::chrono::duration_cast<std::chrono::milliseconds>(
                            std::chrono::steady_clock::now() - start).count());
        if(r){
            state.store(1);
        }else if(r.error() == interruptedError()){
            state.store(2);
        }else{
            state.store(3);
        }
        done.store(true);
        return 0;
    }, Coro::Priority::Normal, Coro::Affinity::sticky());

    QVERIFY2(waitForDone(done, 2000, [&]{ task.cancel(); }), "delay_for did not finish");
    QCOMPARE(state.load(), 1);
    QVERIFY(elapsedMs.load() >= 30);
    QVERIFY(elapsedMs.load() < 1000);
}

/**
 * @brief 任务 cancel 时，delay_for 应提前返回 interrupted。
 */
void test_fiber_task::test_case_delay_for_cancelled()
{
    std::atomic_bool started{false};
    std::atomic_bool done{false};
    std::atomic_int  state{0};
    std::atomic_llong elapsedMs{-1};

    auto task = Coro::makeTask([&]{
        started.store(true);
        const auto start = std::chrono::steady_clock::now();
        auto r = Coro::delay_for(std::chrono::milliseconds(1000));
        elapsedMs.store(std::chrono::duration_cast<std::chrono::milliseconds>(
                            std::chrono::steady_clock::now() - start).count());
        if(r){
            state.store(1);
        }else if(r.error() == interruptedError()){
            state.store(2);
        }else{
            state.store(3);
        }
        done.store(true);
        return 0;
    }, Coro::Priority::Normal, Coro::Affinity::sticky());

    QTRY_VERIFY_WITH_TIMEOUT(started.load(), 3000);
    QTest::qWait(100);
    task.cancel();

    QVERIFY2(waitForDone(done, 2000, [&]{ task.cancel(); }),
             "delay_for did not finish after cancel");
    QCOMPARE(state.load(), 2);
    QVERIFY(elapsedMs.load() >= 0);
    QVERIFY(elapsedMs.load() < 800);
}

/**
 * @brief 零时长应立即成功，不挂起。
 */
void test_fiber_task::test_case_delay_for_zero()
{
    std::atomic_bool done{false};
    std::atomic_int  state{0};
    std::atomic_llong elapsedMs{-1};

    auto task = Coro::makeTask([&]{
        const auto start = std::chrono::steady_clock::now();
        auto r = Coro::delay_for(std::chrono::milliseconds(0));
        elapsedMs.store(std::chrono::duration_cast<std::chrono::milliseconds>(
                            std::chrono::steady_clock::now() - start).count());
        state.store(r ? 1 : (r.error() == interruptedError() ? 2 : 3));
        done.store(true);
        return 0;
    }, Coro::Priority::Normal, Coro::Affinity::sticky());

    QVERIFY2(waitForDone(done, 2000, [&]{ task.cancel(); }), "zero delay_for did not finish");
    QCOMPARE(state.load(), 1);
    QVERIFY(elapsedMs.load() >= 0);
    QVERIFY(elapsedMs.load() < 1000);
}
```

```cpp
#ifndef DELAY_HPP
#define DELAY_HPP

#include <chrono>
#include <system_error>

#include "awaitable.hpp"

namespace Coro {

/**
 * @brief 可被 FiberTask::cancel 提前中止的协程延时
 * @details 内部使用一条无生产者的 Awaitable<void>，通过 await_for(duration) 挂起：
 *          - 正常到期：await_for 返回 timed_out，本函数映射为成功；
 *          - 任务 cancel：当前句柄消费者队列以 interrupted 关闭，本函数返回该错误；
 *          - duration <= 0：立即成功，不挂起。
 *          只响应 task.cancel；Coro::quit()/线程结束不会提前唤醒，仍会等满 duration。
 *          不创建定时线程、不依赖 Qt、不修改 FiberChannel/ChannelHub/await_for。
 * @tparam Rep 时长的计数类型
 * @tparam Period 时长的周期类型
 * @param duration 最长等待时长
 * @return 正常到期成功；取消时返回 std::errc::interrupted
 * @code
 * using namespace std::chrono_literals;
 * auto r = Coro::delay_for(100ms);
 * if(!r && r.error() == std::make_error_code(std::errc::interrupted)){
 *     // 任务被 cancel
 * }
 * @endcode
 */
template<class Rep, class Period>
Result<void> delay_for(const std::chrono::duration<Rep, Period>& duration)
{
    using duration_type = std::chrono::duration<Rep, Period>;
    if(duration <= duration_type::zero()){
        return Result<void>();
    }

    Awaitable<void> a;                  // 无生产者：只等超时或被 task cancel 关闭
    auto r = a.await_for(duration);
    if(r){
        return r;
    }
    if(r.error() == std::make_error_code(std::errc::timed_out)){
        return Result<void>();          // 正常睡满
    }
    return r;                            // interrupted / 其它错误
}

} // namespace Coro

#endif // DELAY_HPP
```
