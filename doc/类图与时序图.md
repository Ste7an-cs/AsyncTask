## 2. 时序图

### 2.1 一次信号等待

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户协程
    participant F as coro() 工厂
    participant A as Awaitable
    participant Q as Qt 信号/槽
    participant S as 调度器

    U->>F: coro(obj, &sig)
    F->>A: 建 Awaitable，取 channel()
    F->>Q: connect(obj, sig, [ch]{ ch->push(...) })
    F->>A: setOnClose(disconnect)
    F-->>U: 返回 Awaitable(按值)
    U->>A: await(a) → ch->pop()
    A->>S: 无数据，挂起当前协程（让出线程）
    Note over S: 线程可执行其它协程
    Q-->>A: 信号触发，槽 push 值
    A->>S: 唤醒该协程
    S-->>U: pop 返回，得到 Result<T>
    U->>A: (析构) setOnClose → disconnect
```

### 2.2 协程跨线程调度

```mermaid
sequenceDiagram
    autonumber
    participant M as 主线程
    participant S1 as 主线程调度器
    participant GQ as FiberGlobalQueue(全局)
    participant S2 as 工作线程调度器
    participant W as 工作线程

    M->>S1: 创建 Shared 协程(launch_properties)
    S1->>S1: awakened(ctx) → ctx.detach()
    S1->>GQ: emplace_back(props) 入 Shared 桶
    Note over M: 主线程阻塞/无法调度该协程
    W->>S2: dispatch 循环
    S2->>GQ: pick_next() → pop Shared 桶
    GQ-->>S2: 取出 ctx
    S2->>W: attach(ctx) 并 resume
    W->>W: 运行协程；sleep/await 时让出，可继续取其它协程
```

### 2.3 FiberTask 链式 then

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant T0 as makeTask 协程
    participant T1 as then 协程
    participant SS as SharedState

    U->>T0: makeTask(fn0) → add_nodes()
    U->>T1: .then(fn1) → add_nodes()
    U->>U: .on_finally(cb) 登记到 finally_cbs
    T0->>T0: 运行 fn0，set_value(结果)
    T0->>SS: done_nodes()
    T1->>T1: 等 T0.future 就绪；检查 is_runnable
    alt 未取消
        T1->>T1: 以 fn0 结果为入参运行 fn1，set_value
    else 已 cancel()
        T1->>T1: 短路，返回中断错误
    end
    T1->>SS: done_nodes() → 计数归零触发 finally_cbs
    U->>T1: get() 返回 Result
```

### 2.4 Coro::quit() 安全退出

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户(end/协程)
    participant App as FiberApplication
    participant AW as 各 Awaitable
    participant Sch as 主线程调度器
    participant Pool as FibersPool

    U->>App: Coro::quit()
    App->>AW: invokeMethod(qApp,"aboutToQuit") → 各 awaitable close(channel)
    AW-->>Sch: 挂起在 await() 的协程被唤醒并收尾
    App->>Sch: drainUntilIdle(): processEvents + yield 直到在途协程/事件跑完
    App->>Pool: block.close() + FibersPool.close()
    App->>App: QCoreApplication::exit()
    Note over App: 协程在 QCoreApplication 析构前收尾，避免退出崩溃/卡死
```
